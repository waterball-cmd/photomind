# 기술 검증

## 실험 목적

MobileCLIP 기반 자연어 의미 검색이 **실제 기기에서 쓸 만한 정확도·속도·용량**을 내는지 확인하고, 의미 검색을 주력 기능으로 둘지 보조 기능으로 낮출지 결정한다.

- 1단계: PC 실험 (`experiments/`, Python) — 모델·방식별 정확도 비교
- 2단계: Android 실험 — 실기기에서 속도·용량 측정

## 합격 기준

| 항목 | 기준 |
|---|---|
| 평가 데이터 | 사진 100장, 검색어 20개 (`experiments/data/queries.csv`) |
| 정확도 | Recall@5 **70% 이상** |
| 속도 | 실기기에서 임베딩 1장당 **0.5초 이내** |
| 용량 | 모델 **150MB 이내** |

**미달 시**: 의미 검색을 보조 점수로 낮추고, 태그·OCR·날짜 검색을 주력으로 한다.
