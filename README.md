# PhotoMind

> 사진의 이름이 아니라, 기억나는 장면으로 찾는 갤러리

PhotoMind는 기기 안의 사진을 AI로 분석해 자동으로 분류하고, "바다에서 찍은 노을", "영수증 사진"처럼 기억나는 장면을 자연어로 검색할 수 있는 Android 앱입니다.

## 핵심 기능

- **자동 사진 분석·분류** — 이미지 라벨링과 얼굴 감지로 사진에 태그를 붙이고 분류합니다.
- **OCR 텍스트 검색** — 사진 속 글자(영수증, 간판, 문서 등)를 인식해 텍스트로 검색합니다.
- **자연어 의미 검색** — 문장으로 묘사한 장면과 의미가 가까운 사진을 찾아 줍니다.
- **온디바이스 처리** — 모든 분석은 기기 안에서 이루어지며, 사진이 외부 서버로 전송되지 않습니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 언어·UI | Kotlin, Jetpack Compose |
| 로컬 저장소 | Room |
| 백그라운드 작업 | WorkManager |
| 사진 접근 | Photo Picker / MediaStore |
| 온디바이스 AI | ML Kit (텍스트 인식 · 이미지 라벨링 · 얼굴 감지 · 오프라인 번역) |
| 모델 실행 | TensorFlow Lite (LiteRT) |
| 의미 검색 모델 | MobileCLIP |

## 사용 오픈소스와 라이선스

| 이름 | 구분 | 라이선스 | 용도 |
|---|---|---|---|
| TensorFlow Lite (LiteRT) | 오픈소스 | Apache License 2.0 | 온디바이스 모델 실행 |
| MobileCLIP | 오픈소스 (코드·모델 가중치) | Apple 라이선스 — **사용 조건 확인 필요** | 이미지·텍스트 임베딩 (의미 검색) |
| ML Kit | **오픈소스 아님** — Google 무료 SDK | Google APIs 이용약관 / ML Kit 약관 | OCR · 이미지 라벨링 · 얼굴 감지 · 번역 |

> ML Kit은 소스가 공개된 오픈소스가 아니라 무료로 제공되는 SDK이므로, 오픈소스 목록과 구분해 표기합니다.
